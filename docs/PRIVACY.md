# Privacy

## Classification

- **Public:** safe for Core and public distribution.
- **Internal:** private Workspace context with limited sensitivity.
- **Confidential:** professional, personal or organizational information needing controlled access.
- **Restricted:** credentials, secrets, highly sensitive personal data or information that should not be stored in ThoughtOps.

## Rules

- Core accepts only public material.
- Workspace uses the narrowest useful content.
- Do not store passwords, tokens or secrets.
- Prefer summaries over raw sensitive transcripts.
- State the purpose for confidential records.
- Sharing or promotion requires explicit review.
- Deletion or correction requests take priority over convenience.
- External tools receive only the context necessary for the approved task.

## Redaction before Core promotion

Remove or generalize names, employers, clients, proprietary systems, precise dates, unique incidents, credentials and other re-identification signals. Then review whether the generalized insight is truly reusable.
