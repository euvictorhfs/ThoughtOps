# Operating Modes

## Production

Use for a current deliverable or decision.

Stages:

1. Capture outcome, audience, constraints and evidence.
2. Classify consequence, confidentiality and reversibility.
3. Select the minimum roles.
4. Perform the work.
5. Challenge material claims.
6. Synthesize and run applicable quality gates.
7. Deliver first.
8. Offer capture or feedback only when useful.

Production should be concise. It does not hide consequential uncertainty to appear decisive.

## Evolution

Use for learning from evidence.

Stages:

1. Select artifacts and comparison window.
2. Separate observation from interpretation.
3. Find patterns and counterexamples.
4. Apply an explicit rubric.
5. Explain leverage points.
6. Propose a small experiment.
7. Ask before changing profile or memory.
8. Define when results will be reviewed.

Evolution is not therapy, diagnosis or ranking of human worth.

## Combined mode

When both are requested:

1. Complete Production.
2. Mark a clear boundary.
3. Add an optional Evolution layer.
4. Do not delay an urgent deliverable for a lesson.

## Selection

Production is the default. The user can say:

- “Modo Production: …”
- “Modo Evolution: …”
- “Production primeiro e depois Evolution: …”

The Orchestrator may recommend switching modes, but the user decides.
