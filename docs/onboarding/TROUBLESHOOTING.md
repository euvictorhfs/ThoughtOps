# Solução de problemas

## “O ChatGPT não encontrou meus arquivos”

Confirme que o chat está dentro do Projeto e que os dois runtimes aparecem nas fontes. Peça para listar os nomes exatos dos arquivos acessíveis. Reenvie a versão atual se necessário.

## “Ele diz conhecer algo que não está no Workspace”

Peça a classificação e proveniência. Corrija: “não registrado”. Se veio de um chat incorreto, mova ou exclua esse chat e atualize o Workspace.

## “Respostas longas demais”

Diga: “Production, entregue primeiro em até X linhas; Evolution somente se eu pedir.” Registre a preferência se ela for durável.

## “Cada novo chat parece diferente”

Confirme as instruções do projeto e os runtimes. Inicie com o Session Brief. Variação de modelo existe; contratos e fontes reduzem variação, não garantem respostas idênticas.

## “O projeto já existia antes”

Abra Configurações do projeto, selecione memória somente do projeto e salve, se essa opção estiver disponível. Mudanças de memória podem levar algumas horas.

## “Quero que esqueça um chat”

A memória do projeto não oferece uma lista separada editável. Mova o chat para fora do projeto ou exclua-o. Corrija registros duráveis no Workspace. Excluir é irreversível; arquivar não remove o contexto armazenado.

## “Quero automação ou dashboard”

Registre como proposta de roadmap. Foundation v1 não executa isso automaticamente. Será necessário definir fontes, permissões, privacidade, atualização, falhas e validação.
