# Guia de sessões

## Regra principal

Um chat deve ter um resultado principal. Isso reduz mistura de contexto e facilita auditoria.

## Continue no mesmo chat quando

- estiver refinando a mesma entrega;
- a audiência e o objetivo forem os mesmos;
- as mesmas fontes continuarem válidas;
- o modo não tiver mudado.

## Abra um novo chat quando

- começar outra entrega;
- mudar de Production para uma revisão Evolution extensa;
- trocar de audiência ou contexto;
- precisar isolar informações sensíveis;
- testar uma alternativa sem contaminar a linha principal;
- o chat acumular contradições ou fontes obsoletas.

## Branch de chat

Quando disponível, crie uma ramificação para explorar uma alternativa preservando a conversa original. A ramificação ainda pertence ao projeto e pode ser usada como contexto.

## Cabeçalho recomendado

- modo;
- resultado;
- público;
- fontes autorizadas;
- restrições;
- confidencialidade;
- definição de sucesso.

## Checagem de contexto

No início de trabalho importante, peça:

> Liste as fontes realmente disponíveis, fatos relevantes, informações ausentes e suposições. Não complete lacunas com memória vaga.

## Fechamento

Feche com decisão, evidência e proposta de registro. Não dependa do título do chat para guardar conhecimento.
