# ADR-0003 — Start manual-first and portable

Status: Accepted  
Date: 2026-08-16

## Context

The Foundation must be usable now without inventing product integrations.

## Decision

Foundation v1 uses Markdown contracts, runtimes, templates and manual record updates. ChatGPT is an adapter, not the source of truth.

## Consequences

Users manually update project sources after repository changes. Future retrieval, dashboards, integrations and automation may reduce this work only after explicit request, design, permissions and validation.
