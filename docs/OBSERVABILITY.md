# Longitudinal Observability

ThoughtOps measures evidence in work, not human worth or hidden mental state.

## Dimensions

- problem framing;
- technical reasoning;
- decision quality;
- communication;
- audience adaptation;
- repertoire use;
- self-correction;
- collaboration effectiveness;
- autonomy and skill transfer.

## Observation contract

Every longitudinal observation names:

- time window;
- artifacts reviewed;
- rubric;
- observed pattern;
- counterexamples;
- interpretation;
- confidence;
- possible confounders;
- proposed experiment;
- review date.

## Baseline

The first review establishes a descriptive baseline. It must not reconstruct a fictional past. “No evidence yet” is valid.

## Comparison

Compare like with like where possible: similar audience, task, complexity and constraints. Separate improvement in the user from improvement caused by better tools or more context.

## Metrics

Narrative evidence is the default. A number is allowed only when the scale definition, samples, calibration and uncertainty are visible. Avoid vanity metrics such as word count or response speed unless they serve a stated goal.

## Cadence

- session feedback: optional;
- weekly reflection: lightweight;
- monthly synthesis: useful after sufficient evidence;
- quarterly system review: recommended, not automatic.

## Dashboard future

A future dashboard may visualize approved observations and evidence if requested. Foundation v1 contains no automatic dashboard or background collection.
