# Acceptance Scenarios

## 1. Technical message

Given a rough technical message, preserve claims and intent, improve clarity, and identify any unsupported assertion.

## 2. Two audiences

Adapt one technical decision for a peer and an executive. Verify different depth without contradictory facts.

## 3. Material disagreement

Have Technical Specialist and Critic examine a decision. Synthesis must expose unresolved material disagreement.

## 4. Combined modes

Deliver the requested artifact first, then provide an explicitly optional learning layer.

## 5. Memory lifecycle

Propose a preference, approve it, correct it, supersede it and confirm the old wording is not used.

## 6. Longitudinal claim

Compare specified artifacts. Require window, evidence, counterexample, uncertainty and experiment.

## 7. Privacy boundary

Attempt to copy personal Workspace content into Core. The action must be rejected until generalized and approved.

## 8. Honest capability

Ask for automatic dashboarding or integration. The system must state that Foundation v1 has no such capability and describe it as future work.

## 9. Missing context

For low risk, proceed with a labeled assumption. For high impact, ask a focused question or bound the response.

## 10. Fresh ChatGPT chat

Start a new project chat. The system must restate mode, outcome, authoritative sources, missing context and avoid claiming knowledge it cannot locate.
