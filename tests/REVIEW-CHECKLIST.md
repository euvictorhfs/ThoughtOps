# Foundation Review Checklist

- [ ] No personal or proprietary information exists in Core.
- [ ] README gives a nontechnical first-use path.
- [ ] Core and Workspace responsibilities do not overlap ambiguously.
- [ ] Constitution has clear precedence.
- [ ] Every role has a responsibility and limit.
- [ ] Production and Evolution have distinct lifecycle.
- [ ] Chat is not treated as automatic durable memory.
- [ ] Facts, hypotheses and observations are distinct.
- [ ] Longitudinal claims require evidence and uncertainty.
- [ ] Communication preserves intent and voice.
- [ ] High-risk missing context is surfaced.
- [ ] No nonexistent integration, automation or dashboard is claimed.
- [ ] Future capabilities require request, design and approval.
- [ ] Templates satisfy artifact schemas.
- [ ] Acceptance scenarios can be completed manually.
- [ ] Links and filenames are coherent.
- [ ] No TODO, TBD or placeholder remains.
