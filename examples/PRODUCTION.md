# Production Example

**Brief:** Rewrite a deployment-risk update for an engineering manager. Preserve the facts; make the request explicit.

**Orchestration:** Production. Communication Editor + Technical Specialist + Critic.

**Result structure:**

1. Current state
2. Material risk and evidence
3. Decision or support requested
4. Owner and timing

**Quality:** Preserve technical meaning, label uncertainty, avoid inventing dates or commitments.

**Capture:** Offer to record a decision only if the user actually decides.
