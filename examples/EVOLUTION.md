# Evolution Example

**Evidence:** Three user-selected status updates from one month.

**Observation:** Two updates state detailed context before the decision request. One counterexample leads with the request.

**Interpretation:** The pattern may increase reading effort for decision-makers. Confidence is medium because audience feedback is absent.

**Experiment:** For the next three comparable updates, lead with the decision or action requested, then context.

**Review:** Compare response clarity and stakeholder feedback after the three samples.

No personal trait is inferred and no memory changes without approval.
